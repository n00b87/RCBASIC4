function GetActorCollisionShape(actor)

Returns the actor's collision shape

Possible values:

  • ACTOR_SHAPE_NONE
  • ACTOR_SHAPE_BOX
  • ACTOR_SHAPE_SPHERE
  • ACTOR_SHAPE_CYLINDER
  • ACTOR_SHAPE_CAPSULE
  • ACTOR_SHAPE_CONE
  • ACTOR_SHAPE_CONVEXHULL
  • ACTOR_SHAPE_TRIMESH
