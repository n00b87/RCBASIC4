Function GetActorType( actor )

Returns an actor's type

Actor Types

  • ACTOR_TYPE_NONE
  • ACTOR_TYPE_MESH
  • ACTOR_TYPE_OTMESH
  • ACTOR_TYPE_LIGHT
  • ACTOR_TYPE_TERRAIN
  • ACTOR_TYPE_WATER
  • ACTOR_TYPE_BILLBOARD
  • ACTOR_TYPE_PARTICLE
  • ACTOR_TYPE_PRIMITIVE
  • ACTOR_TYPE_PROJECTOR
  • ACTOR_TYPE_COMPOSITE
  • ACTOR_TYPE_VEHICLE

NOTE: Cube and Sphere actors both return ACTOR_TYPE_PRIMITIVE
