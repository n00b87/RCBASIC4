sub setMaterialAntiAliasing( material_id, aa)

Sets the anti-aliasing mode for the material

Possible modes returned

  • AA_MODE_OFF
  • AA_MODE_SIMPLE
  • AA_MODE_QUALITY
  • AA_MODE_LINE_SMOOTH
  • AA_MODE_POINT_SMOOTH
  • AA_MODE_FULL_BASIC
  • AA_MODE_ALPHA_TO_COVERAGE
